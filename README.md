
# Projeto de PPO

### RESUMO

Nesse projeto aplicamos na pratica os design patterns na construção de um sistema, esse sistema tem como objetivo auxiliar o controle e execução dos servicos de uma empresa de TI.

### LINGUAS

- java

### DESIGN PATTERNS

- Solid
- Decorator
- Factory Method
- Abstract
- Builder


### OBJETIVO

O projeto e um sistema de cadastro de serviços, listaos, permite que autere os dados cadastrados e exclua os servicos registrados para que a empresa de tecnologia possa gerenciar diversos serviços.
