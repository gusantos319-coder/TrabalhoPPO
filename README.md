
# Projeto de PPO

### RESUMO

Nesse projeto aplicamos na pratica os design patterns: Decorator, Factory Method, Abstract, Builder e o Solid.

### LINGUAS

- java

### DESIGN PATTERNS

- Solid
- Decorator
- Factory Method
- Abstract
- Builder


### OBJETIVO

O projeto e um sistema de cadastro de serviços para uma empresa de tecnologia que presta diversos serviços.
